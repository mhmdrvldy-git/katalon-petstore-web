# Katalon Petstore Web Automation

Web UI automation framework developed with **Katalon Studio** for testing web interfaces.

## 🚀 Project Overview
This repository handles frontend/web-based scenarios, UI component validation, and user journey workflows.

## 🛠️ Tech Stack
- **Test Engine:** Katalon Studio
- **Language:** Groovy
- **Browser:** Chrome / Firefox (Headless supported)

## 📂 Project Structure
- `Object Repository/`: Web UI element locators (XPaths, Web Elements).
- `Test Cases/`: Step-by-step UI test scenarios.
- `Test Suites/`: Execution management suites.

## ⚙️ How to Run
1. Open Katalon Studio and open this project repository.
2. Select your target browser from the toolbar dropdown.
3. Open the desired Test Suite and click **Run**.

## 📊 Test Coverage & Scenarios
- UI element visibility, form submissions, navigation paths, and interactive component verification.
